# Global Exception Handling

## Objective

Instead of writing try-catch blocks inside every controller method, a centralized exception handling mechanism was implemented using:

```java
@RestControllerAdvice
```

This ensures:

- Cleaner controllers
- Centralized error handling
- Consistent API responses
- Better maintainability

---

## Validation Exception Handler

Validation errors generated by:

```java
@Valid
```

are handled using:

```java
@ExceptionHandler(MethodArgumentNotValidException.class)
public ResponseEntity<ApiResponse<?>>
handleInputValidation(
        MethodArgumentNotValidException exception) {

    // validation handling logic
}
```

---

## Validation Flow

```text
Client Request
      ↓
Controller
      ↓
@Valid Validation
      ↓
Validation Failed
      ↓
MethodArgumentNotValidException
      ↓
GlobalExceptionHandler
      ↓
Custom API Error Response
```

# Question 5

# Custom Annotation - Prime Number Validation

## Objective

Create a custom validation annotation that checks whether a number is Prime Number.

Since Hibernate Validator does not provide a built-in Prime Number validator, a custom annotation was created.

---

## Custom Annotation

```java
@Documented
@Target(ElementType.FIELD)
@Retention(RetentionPolicy.RUNTIME)
@Constraint(validatedBy = PrimeNumberValidator.class)
public @interface PrimeNumber {

    String message() default
            "Number should be Prime Number!!";

    Class<?>[] groups() default {};

    Class<? extends Payload>[] payload() default {};
}
```

---

## Validator Class

```java
public class PrimeNumberValidator
        implements ConstraintValidator<PrimeNumber, Integer> {

    @Override
    public boolean isValid(Integer value,
                           ConstraintValidatorContext context) {

        if (value == null || value <= 1) {
            return false;
        }

        for (int i = 2; i <= Math.sqrt(value); i++) {
            if (value % i == 0) {
                return false;
            }
        }

        return true;
    }
}
```

---

## Usage

```java
@PrimeNumber
private Integer primeNumber;
```

---

## Examples

### Valid

```json
{
    "primeNumber": 13
}
```

### Invalid

```json
{
    "primeNumber": 56
}
```

Response:

```json
{
    "primeNumber": [
        "Number should be Prime Number!!"
    ]
}
```

# Question 6

# Custom Annotation - Password Validation

## Objective

Create a reusable password validator that enforces password strength rules.

---

## Validation Rules

A valid password must:

- Contain at least one uppercase letter
- Contain at least one lowercase letter
- Contain at least one special character
- Have a minimum length of 10 characters

---

## Custom Annotation

```java
@Documented
@Target(ElementType.FIELD)
@Retention(RetentionPolicy.RUNTIME)
@Constraint(validatedBy = PasswordValidator.class)
public @interface ValidPassword {

    String message() default
            "Password must contain at least one uppercase letter, one lowercase letter, one special character and be at least 10 characters long";

    Class<?>[] groups() default {};

    Class<? extends Payload>[] payload() default {};
}
```

---

## Validator Class

```java
public class PasswordValidator
        implements ConstraintValidator<ValidPassword, String> {

    @Override
    public boolean isValid(String password,
                           ConstraintValidatorContext context) {

        if (password == null || password.length() < 10) {
            return false;
        }

        boolean upper = false;
        boolean lower = false;
        boolean special = false;

        for (char ch : password.toCharArray()) {

            if (Character.isUpperCase(ch)) {
                upper = true;
            }
            else if (Character.isLowerCase(ch)) {
                lower = true;
            }
            else if (!Character.isLetterOrDigit(ch)) {
                special = true;
            }
        }

        return upper && lower && special;
    }
}
```

---

## Usage

```java
@ValidPassword
private String password;
```

---

## Valid Examples

```text

JavaDeveloper@
```

---

## Invalid Examples

```text
abc
```

Reason:

- Length < 10
- No uppercase letter
- No special character

---


Reason:

- No lowercase letter
